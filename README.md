# 沙罗曼蛇 · SALAMANDER H5

AI 多智能体协作开发的单文件 HTML5 纵版/横版射击游戏。**双击 `index.html` 即玩**，手机浏览器直接打开，断网可玩，无需安装、无需后端。

- 单文件 `index.html` ≈ 875 KB（895,570 B），**0 图片 / 0 音频 / 0 外部依赖**：画面全部由 Canvas 2D 程序化绘制，音乐与音效由 WebAudio 实时合成
- 6 关完整流程（横版洞窟 ↔ 纵版太空交替推进）+ 6 个三阶段关底 BOSS + 道中 BOSS + 终局逃生段
- 8 类字母胶囊即时强化、5 种主武器、P 能量条 7 格、BOMB 全屏清弹、OVERDRIVE 超频
- 双人同屏（键盘双打 / 手机左右半屏双指同操）
- 横竖屏随关卡自动切换（16:9 / 9:16），手机竖握一键全屏锁横屏

## 操作

| 键 | 作用 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| `J` / `Z` | 射击（2P 用 `IJKL`） |
| `SPACE` | 激活能量胶囊强化 |
| `P` | 暂停 |
| `M` | 静音 |
| `X` / 触屏右下 BOMB | 释放炸弹 |

## 致谢与原创边界

关卡流程结构致敬 Konami 1986《沙罗曼蛇》；**美术与音乐全部为原创程序化生成，未使用任何原作素材**（不含原作采样、旋律转录或图形资源）。本项目为 fan remake，仅用于学习与作品展示。
